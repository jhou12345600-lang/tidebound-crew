# 怒海同舟 3D

網頁版 3D 多人同船航海冒險：和好友一起開同一艘帆船，有人掌舵、有人調帆、有人下艙補洞舀水、有人開砲；照著藏寶圖上島挖寶，扛回潮聲港換金幣，小心黑鯊海盜團和暴風雨。

- `index.html`：打包好的完整遊戲（GitHub Pages 直接用這個）
- `src/`：原始碼（海浪、島嶼、船隻、權威模擬、連線、介面、音效）
- 重新打包：`npm i esbuild three@0.170.0 mqtt@5.10.1 && node build.mjs`，再把 `dist/index.html` 複製到根目錄
- 多人連線：房主按「建立房間」，把網址（`?room=房號`）傳給朋友；透過 MQTT 公共伺服器同步，房主的電腦負責模擬船隻、敵船和砲彈

## 操作
WASD 走路、滑鼠看、左鍵使用道具、E 互動、1–6 換道具、G 放下寶箱、R 裝填砲彈、M 航海圖、H 說明、Enter 聊天
