# 怒海同舟 3D

網頁版 3D 多人同船航海冒險：和好友一起開同一艘帆船，有人掌舵、有人調帆、有人下艙補洞舀水、有人開砲；照著藏寶圖上島挖寶，扛回潮聲港換金幣，小心黑鯊海盜團和暴風雨。

- `index.html`：打包好的完整遊戲（GitHub Pages 直接用這個）
- `src/`：原始碼（海浪、島嶼、船隻、權威模擬、連線、介面、音效）
- 重新打包：`npm i esbuild three@0.170.0 mqtt@5.10.1 && node build.mjs`，再把 `dist/index.html` 複製到根目錄
- 帳號與好友：註冊／登入、加好友、看好友在線與所在房間、一鍵加入或邀請、存檔（金幣與強化）跟著帳號走。資料存在 MQTT 公共伺服器的保留訊息並在本機備份，沒有自己的後端，請勿使用重要密碼。
- 多人連線：登入後「開房出航」，好友可從好友清單加入，也能用網址（`?room=房號`）；房主的電腦負責模擬船隻、敵船、砲彈、城堡守軍
- 雇用船員：在港口雇砲手（自動瞄準開砲）、帆手（自動吃風、聽令放收帆）、錨手、船匠（自動補洞舀水滅火）、陸戰隊（上岸攻城、挖寶、搬寶箱），按 C 下命令
- 世界：潮聲海、北冰海、東珊瑚海、南火山海、西霧海五片海域，各有港口與城堡；國際海警與通緝等級；九種強化

## 操作
WASD 走路、滑鼠看、左鍵使用道具、E 互動、1–7 換道具（7 是火槍）、G 放下寶箱、R 裝填砲彈、T 換彈種、M 航海圖、F 好友、H 說明、Enter 聊天
